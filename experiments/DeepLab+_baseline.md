# Day 3 实验记录：DeepLabV3+

## 1. 实验目的

学习 DeepLabV3+ 网络的基本结构，理解 ASPP（空洞空间金字塔池化）模块的工作原理，并使用 CWFID 数据集完成植被与背景二分类语义分割实验。

## 2. 实验环境

- Python：3.11.18
- PyTorch：2.15.0+cu132
- GPU：NVIDIA GeForce RTX 5060 Laptop GPU
- 数据集：CWFID
- 图像数量：60
- 训练集：48
- 验证集：12
- 数据划分随机种子：42

## 3. 模型配置

- 网络：DeepLabV3+
- Backbone：ResNet18
- Encoder预训练权重：None
- Decoder Channels：256
- 输入尺寸：288×384
- Batch Size：4
- Epochs：30
- Optimizer：Adam
- Learning Rate：0.0001
- Loss Function：BCEWithLogitsLoss + Dice Loss
- 输出类别：1（植被）
- 总参数量：12.329M

## 6. 实验现象

1. 前三个 Epoch 的 Dice 均为0，随后开始逐渐提升。
2. 验证 Loss 总体下降，但部分 Epoch 存在波动。
3. 第28轮 Dice 出现明显下降，第29、30轮恢复。
4. 第30轮取得本次实验最佳验证 Dice。

## 7. 实验分析

DeepLabV3+ 通过 ASPP 模块获取多尺度上下文信息，并利用 Decoder 融合不同层次的特征。

本次实验成功完成训练和验证集逐图评价。模型验证 Dice 为0.8259，IoU 为0.7040。

与之前的 U-Net 和 U-Net++ 实验相比，本次 DeepLabV3+ 的验证指标较低。由于当前数据集只有60张图像，且尚未进行独立测试，因此不能仅凭此次验证结果判断网络的普遍性能优劣。
